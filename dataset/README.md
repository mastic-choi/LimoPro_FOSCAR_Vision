# dataset/

실차 주행 프레임 모음. 이미지는 용량이 커서 gitignore(`dataset/*`), 이 문서만 추적한다.
스크립트의 `--frames`에는 프레임이 바로 들어 있는 폴더(세션 폴더)를 넘긴다.
파일명은 `frame_NNNNNN.{png,jpg}`로 통일(스크립트가 둘 다 읽음).

## LimoPro_frames_20261027

- 원본: Google Drive 내보내기 `20261027-20261028T005547Z-1-001.zip` (2026-10-28 받음)
- 카메라: Orbbec Dabai DC1 (UVC color, MJPG), **1280×720**, 30fps 캡처 → 저장 10fps 설정
  (실제 간격 평균 0.116s ≈ 8.6Hz, `timestamps.csv`의 `unix_time` 기준)
- 정리 내용: `images/NNNNNN.jpg` → `frame_NNNNNN.jpg`로 이름 변경하고 세션 폴더 바로 아래로 올림,
  `timestamps.csv`의 `filename` 열도 같이 갱신. Drive가 만든 중복본 `NNNNNN(1).jpg` 15장
  (session_183234, 원본과 바이트 동일 확인)은 삭제.
- **정지 중복 제거**: 캡처 스크립트가 주행 여부와 상관없이 계속 찍어서 멈춰 있는 동안 같은 장면이 쌓임.
  바로 앞 프레임과 화면 전체(160×90 흑백) 평균 절대차가 **2.5 미만**이면 제거 → 정지 구간마다 첫 장만 남음.
  (정지 상태 노이즈 ~1.5~2, 주행 중엔 대부분 6 이상이라 경계가 뚜렷함. 바닥만 보거나 블러를 걸면
  균일한 검은 매트 때문에 주행 프레임까지 걸려서 화면 전체·원본 그대로 비교.)
  지운 프레임 목록은 각 세션의 `removed_still_frames.csv`. 파일 번호는 원본 그대로라 중간에 빈 번호가 있다.

| 세션 | 남은 프레임 (원본) | 시간 | 내용 |
|---|---|---|---|
| `session_183215` | 2 (118) | 18:32:15~18:32:28 (13s) | 정지 상태 테스트 촬영. 카메라 고정, 사람만 걸어다님 |
| `session_183234` | 8232 (8465) | 18:32:34~18:48:56 (16m 22s) | 트랙 주행 본편. 결측 없음, 0.2s 넘는 간격 1회(0.26s). 제거된 정지 구간: 출발 전 0~63, 2071~2086, 4536~4558, 6652~6667, 주행 후 8275~8464 대부분(벽/인조잔디, 조금씩 움직인 십여 장은 남음) |

장면: 검은 매트 트랙 + 노란 실선/흰 점선, 횡단보도·마름모·글자 노면표시, 실내(흰 벽, 유리 칸막이, 사람·박스).

각 세션 폴더: `frame_*.jpg`, `timestamps.csv`(`index,filename,unix_time,mono_time`, 남은 프레임만),
`removed_still_frames.csv`(같은 형식, 지운 프레임), `meta.json`(캡처 설정).

> 주의: 기존 `LimoPro_frames_20261023`(640×480)과 해상도·카메라가 다르다.
> `scripts/make_ego_lane_labels.py`의 추적 파라미터는 640×480 픽셀 기준이라 이 데이터에 그대로 쓰면 안 맞을 수 있다.
