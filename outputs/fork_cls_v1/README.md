- `light_tint`: 크롭(BGR)에 조명 색 이득(빨강 1.0 = B×0.1, G×0.2, R×1.2 / 파랑 1.0 = B×1.2, G×0.25, R×0.1)을 곱하고 그 색 빛을 조금 더함. 흑백 변환 전.
- 결과: **가림 모델(v0.1)도 이미 버팀** — 학습에 안 쓴 실차 B·뒤집은 B 는 모든 조명에서 98~99% 맞음, 반대쪽 오답 0%. 조명 모델도 같음(파랑 1.0 뒤집은 B 에서 반대 1%).
  흑백 + CLAHE 가 색 이득을 대부분 지움. 그래서 로봇 모델은 v0.1 그대로 두고, 실물 A·B 로 다시 학습할 때 `--tint-prob 0.5` 를 같이 쓴다.
- 이 시험은 색 이득 흉내일 뿐. 실제 대회장 빛(번짐·반사·노출)은 그 조명에서 녹화한 bag 으로만 확인됨.
