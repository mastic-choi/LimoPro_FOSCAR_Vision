# fork_cls_v2 — 실물 Ø80 mm A·B 주행 추가 (2026-11-16 밤, 사전 릴리즈 `fork-sign-v0.2`)

v0.1 (`fork_cls_v1/final_l3_mask`)은 실물 A 를 본 적이 없었습니다(실차 bag 은 모두 노트북 화면의 B, A 는 뒤집은 B).
11-16 밤 실물 크기 인쇄 표지판(규정집 v3, Ø80 mm, 받침대)으로 M7 을 5번 돌린 원본 영상으로 크롭을 만들어 다시 학습했습니다.

글자는 사람이 몽타주로 확인했습니다(한 주행 안에서는 표지판이 안 바뀜).

만든 순서:
1. `scripts/fork_real_detect.py`: multitask-v3real 검출을 640×360 전체와 2배 확대 타일(원본 y 100~460, x 0/320/640)로 돌림 → 표지판류 후보 + 분류기(v0.1) 확률.
2. `scripts/fork_real_sam2_track.py`: 분류기가 표지판이라 한 가까운 박스를 시작점으로 SAM 2.1(hiera-base+) 영상 추적 → 모든 프레임의 표지판 박스.
3. `scripts/fork_real_sam2_far.py`: 가까운 구간에서 거꾸로 따라가면 사이에 표지판이 약 100 프레임 화면 밖으로 나가서 놓칩니다.
   먼 구간(장애물 사이, 약 300~360)과 아주 먼 구간(3차선 구간 차로 끝, 약 75~200)은 HybridNets sign 검출(0.7~0.9)을 시작점으로 따로 추적합니다.
   주행마다 박스 203~258장(아주 먼 79~110, 먼 16~27, 가까운 99~131). 검출과 IoU 중앙값 0.75~0.79.
4. `scripts/fork_real_crops.py`: SAM2 박스를 로봇과 같은 크롭 규칙으로 원본에서 자름(2 프레임에 1장). 지름 < 60 px(흐려서 화살표가 안 보임),
   화면 끝에 닿음, 가로/세로 비 0.75~1.33 밖(가림)은 버림. 없음 = 일반 검출의 표지판류 후보 중 표지판과 안 겹치는 것(3 프레임에 1장).

기존 데이터는 그대로: 합성 `synth`, 노트북 화면 B `bag_030233`·`bag_030611`, USB 의 화면 B bag 5개(`bag_1115_234946`, `bag_1116_0142..`·`0146..`·`1817..`·`1830..`, B 192 / 없음 186).

## 교차 검증 (`run_cv.sh`, 실물 A 1개 + B 1개 주행을 학습에서 빼고 시험)

공통 `--mask-prob 0.5 --tint-prob 0.5`, 특징 layer3, 고르기 규칙 0.6 / 0.2.

| 설정 | cv1 실물 A / B (220858, 215318) | cv2 실물 A / B (214321, 213635, 빨간 조명) | 실물 A↔B | 합성 대회장 A↔B / 재현율 | 합성 test_bag A↔B / 재현율 |
|---|---|---|---:|---|---|
| **`--flip-real-b` (채택)** | **100% / 98%** | **98% / 100%** | **0** | 0 / 89~91% | 0 / 85~92% |
| 뒤집기 없음 | 98% / 96% | 97% / 100% | 0 | 0 / 91~93% | 0~**1** / 92% |

- 학습에 안 쓴 실물 주행에서 A 와 B 를 한 번도 헷갈리지 않았습니다. 놓친 것은 "없음"(판단 보류)입니다. 실물의 없음을 표지판으로 본 것 0%.
- 실물 A 가 생겼어도 뒤집은 B 를 A 로 같이 쓰는 쪽이 실물 A·B 모두 조금 높습니다.
