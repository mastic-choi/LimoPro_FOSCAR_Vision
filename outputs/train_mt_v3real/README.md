# 다중 작업 3차 + 실물 신호등 결과 (`multitask-v3real`, 2026-11-13)

3차(`multitask-v3`)에서 이어서, 로봇 카메라로 찍은 **실물 신호등 사진**을 섞어 RTX 3070 Ti PC(foscar)에서 30 epoch 더 학습했습니다.
v3는 합성 신호등으로만 배워서 실물 신호등의 노란불·초록불을 거의 잡지 못했습니다. 이번 학습은 그 문제를 고치려는 것입니다.
릴리즈 가중치는 **epoch 29**입니다. val loss 최저와 val 점수(da+ll+mAP50) 최고가 같은 epoch이라 후보는 하나뿐이었습니다. 릴리즈 [`multitask-v3real`](https://github.com/mastic-choi/LimoPro_FOSCAR_Vision/releases/tag/multitask-v3real)에 있습니다.

## 한 줄 요약

- **실물 신호등을 잡게 됐습니다.** 수집 영상 test 171장에서 점수 0.5 기준 노랑 71% → **100%**, 초록 22% → **100%**, 빨강 82% → **96%**입니다. 불빛 오탐은 0.3 기준 10개 → **1개**입니다.
- **1.2m 거리(별도 촬영 12장)의 노란불도 잡습니다.** 0% → **100%**입니다. 초록은 점수 0.3 기준 0% → 75%이고, 0.5 기준으로는 **여전히 0%**입니다([주의](#주의) 참고).
- **차선이 오히려 좋아졌습니다.** ll이 기존 test 0.802 → **0.822**, test_bag 0.810 → **0.845**입니다. 3차에서 내려갔던 ll이 2차(0.816 / 0.826)보다 높아졌습니다.
- **합성 test 검출도 같거나 조금 나아졌습니다.** 콘·몸체 뺀 mAP50이 0.969 / 0.979 / 0.987 → **0.978 / 0.980 / 1.000**입니다(기존 / 대회장 / bag).
- **땡땡이 모니터 앞 가짜 불빛이 4개 → 0개**입니다(193장, 점수 0.3).
- **콘은 학습하지 않았습니다.** 콘 출력은 쓰지 마세요(미션 8은 라이다로 처리). 출력 12클래스 구조는 그대로라 TensorRT 변환이나 C++ 노드는 바꿀 필요가 없습니다.
- **흰 가로선 IoU(대회장)는 0.645 → 0.618로 내려갔습니다.**

## 바꾼 것 (3차 대비)

| | 3차 | 3차 + 실물 |
|---|---|---|
| 시작 가중치 | 2차 best.pt | 3차 릴리즈(`hybridnets_mt_v3_best.pt`, epoch 11) |
| 실물 신호등 | 없음 | `real_tl_v1`: train 961장을 epoch마다 2번 넣음. val 163장, test 171장, test_1m2 12장. 분할 라벨이 없어 차선 손실에는 들어가지 않음 |
| 콘 | `cones_v1` 학습 | 안 씀(`--det-data none`) |
| 신호등 뒤 방해 모니터 | 합성 사진의 40% | 같은 비율로 **실물 사진에도** 그림(절반은 땡땡이) |
| lr | 검출 머리·BiFPN 1e-3, 나머지 1e-4, 120 epoch에 맞춘 감소 | 5e-5(검출 머리·BiFPN은 x10), **30 epoch에 맞춘 감소** |
| BatchNorm | 학습 | 통계를 v3 값으로 고정(`--freeze-bn`). v3는 batch 32였고 여기서는 8이라 통계가 흔들리지 않게 함 |
| 조기 종료 | val loss 5 epoch | val loss 4 epoch(이번에는 걸리지 않고 30 epoch을 다 돎) |
| 차선 보호 | val da+ll이 시작보다 0.01 넘게 낮으면 best에서 제외 | 같음(이번에는 한 번도 걸리지 않음) |
| 그 밖 | 작은 박스(14px 미만) 무시, A/B 2배, 대회장 조명 증강 | 같음 |
| 장비 | H100, batch 32, bf16 | RTX 3070 Ti, batch 8, bf16, `GPU_DUTY` 0.9 |

epoch당 358초, 30 epoch에 약 3시간이 걸렸습니다. GPU 메모리는 약 6.2GB를 썼습니다. 실행 방법은 [`tools/rtx_mt_v3real/README.md`](../../tools/rtx_mt_v3real/README.md)에 있고, 학습 기록은 [`train_run/`](train_run/)과 [`hybridnets_mt_v3real_log.csv`](hybridnets_mt_v3real_log.csv)에 있습니다.

## 점수 보정

`hybridnets_mt_v3real_calib.json`에 val로 맞춘 클래스별 temperature가 있습니다. `p' = sigmoid(logit(p) / T[클래스])`로 씁니다.
불빛은 빨강 0.718, 노랑 0.572, 초록 0.684이고, 신호등 몸체는 0.29입니다. 모두 1보다 작아서, 보정하면 0.5보다 높은 점수는 더 높아지고 낮은 점수는 더 낮아집니다.

## 주의

- **실물 test는 학습과 같은 수집 영상에서 나왔습니다.** 시간 구간은 떼어 두었지만 장소, 조명, 신호등이 같아서 실제보다 좋게 나왔을 수 있습니다. 따로 찍은 사진은 test_1m2 12장뿐입니다. 실차에서 꼭 확인하세요.
- **1.2m 초록불은 점수가 낮습니다.** 4개 중 3개는 0.3과 0.5 사이 점수로 잡히고, 1개는 0.3 미만입니다. 주행 코드가 불빛에 0.5 기준을 쓰면 먼 초록불을 놓칠 수 있습니다. 불빛 기준을 0.3 근처로 낮추거나, 가까워질 때까지 몇 프레임 지켜보는 방식을 추천합니다.
- **콘 출력은 쓰지 마세요.** 콘 데이터 없이 학습해서 v3보다 나빠졌을 수 있고, 이번에는 채점하지 않았습니다.
- **흰 가로선 IoU(대회장)가 0.645 → 0.618로 내려갔습니다.** 정지선을 이 출력으로 판단한다면 실차에서 v3와 비교해 보세요. 대회장 bump AP도 0.986 → 0.955로 조금 내려갔습니다.
- **점수 분포가 v3와 다릅니다.** 주행 코드의 점수 기준을 다시 확인하세요.
- 시드 1개 기준입니다.
