**원본 HybridNets(BDD100K 공개 가중치)에서 새로 학습**합니다. 실행 방법·설정·속도 대응은 [`tools/h100_mt_v4/README_H100.md`](../tools/h100_mt_v4/README_H100.md),
데이터 만드는 도구는 [`tools/mt_v4_data/`](../tools/mt_v4_data/README.md).

## v3real 과 바뀐 것
| 항목 | v3real | v4 |
|---|---|---|

| 갈림길 표지판 | sign_A / sign_B 두 클래스 | **fork_sign 하나**(1번 칸). A/B 는 갈림길 분류기(`fork-sign-v0.2`)가 정함. 출력 12칸은 그대로 |
| 작은 박스 | √넓이 14 px 미만 무시 | **무시 안 함** (먼 표지판 10~17 px 도 학습) |

| 실차 데이터 | 실물 신호등 사진 | + USB bag 834장(사람 검수, da·ll·정지선·박스) + 실물 Ø80 mm A·B 주행 641장(SAM 2.1 추적 박스) |

## 데이터 (`LimoPro_dataset_mt_v2`, 3.9 GB, 저장소에는 안 올림)
- `synth_signs_v2`: train 9,304 / val 326 / test 542 / test_venue 143 / test_bag 42. 정지선 라벨 train 2,500 / val 105 / test 142 / test_venue 88.
  - 정지선 검수: 두 데이터셋 모든 프레임에 v3real 정지선 확률을 구해 잡힌 프레임(확률 > 0.5 픽셀 ≥ 80)과 기존 라벨 프레임 2,432묶음(4,014장)을 사람이 판정
    (모델 맞음 1,187 / 정지선 없음 437 / 애매 695 / 기존 맞음 113). 같은 배경 변형은 한 장 보고 묶음에 적용.
- `bag_mt_v1`: USB rosbag 27개에서 0.5 s 마다 2,000장 → 멈춤·손에 든 것·불확실 573장 빼고 → 사람 검수(1,427장 전부).
  train 834(양 줄이려고 404장 뺌), test_bag1116 184(bag 하나 통째, 공정한 시험).
- `real_fork_v1`: 실물 A·B M7 주행 5개를 10 Hz 로. 표지판은 SAM 2.1 추적(아주 먼 75~200, 먼 300~360, 가까운 440~590 프레임 구간),
  다른 표지판류 검출은 이 주행엔 없으므로 배경. train 641(B·B·A), test 462(A·B).
- `real_tl_v1`, `venue_ref_20261106`: v3real 과 같음.

## 시험 (`test.json`)
test, test_venue(정지선 IoU), test_bag, test_real(실물 신호등), **test_bag1116**(사람 검수 실차), **test_real_fork_v1**(학습에 안 쓴 실물 A·B 주행의 fork_sign).

## 로봇 쪽 (팀 레포, 이 저장소에서는 안 고침)
- 1번 칸 이름이 fork_sign 이 됨. 2번 칸은 학습 데이터가 없어 점수가 거의 안 나옴.
- M7 통과 모드(갈림길 분류기 없음)는 인지의 sign_A/B 로 방향을 정했는데, 합치면 방향을 못 정함 → 분류기 필수, 또는 통과 모드 기본 방향.
