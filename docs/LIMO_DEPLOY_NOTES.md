# LIMO PRO 배포 메모: 차선 모델이 보드에서 돌아갈까

2026-10-31 정리. 아직 보드에서 모델을 돌려 보지 않았다. 아래 내용은 문서 확인과 이 PC 측정을 바탕으로 한 판단이며, 실측으로 바꿔야 한다.

근거 자료:
- 로봇 현황: `LIMO 로봇 기능 현황.docx` (2026-10-26 기준, SSH로 코드와 설정을 확인한 문서. 노드를 실행해 본 문서는 아님)
- 대회 규정: `Autorace2026_규정집.pdf` (10-08 초안 수정본), 트랙 도면 `2026Track 도면.pdf`

## 결론

- 두 모델 모두 주행에 필요한 속도를 낼 가능성은 있지만 장담할 수 없다. 현황 문서에 Jetson 모듈명이 없고 보드 실측 기록도 없다.
- 먼저 TwinLiteNet+ Large를 올려 보고, 속도가 남으면 HybridNets를 시험한다.
- 주행 코드는 다른 팀원 담당이다. 출력 연결은 그 레포에서 협의한다.

## 보드

| 항목 | 내용 |
|---|---|
| 보드 | NVIDIA Jetson (aarch64). 모듈명은 문서에 없음 |
| 소프트웨어 | Ubuntu, ROS 2 Humble, JetPack 6 계열, CUDA 12.6, TensorRT 10.3 |
| 카메라 | Orbbec Dabai DC1 |
| 디스크 | 116GB 중 57GB 남음 (10-26 기준) |

## 필요한 속도

목표는 10~15 FPS다.
- 기존 `limo_control`이 0.1초마다 명령을 낸다.
- 규정 권고 속도 0.3~0.4m/s에서, 0.35m/s면 10 FPS일 때 프레임당 약 3.5cm 움직인다.
- 나중에 신호등/표지판 YOLO가 같은 GPU를 나눠 쓴다. 차선 모델만으로 빠듯하면 안 된다.

## 모델 비교

| | TwinLiteNet+ Large | HybridNets |
|---|---|---|
| 1차 test da / ll | 0.954 / 0.784 | 0.967 / 0.809 |
| 1차 test 커브 da / ll | 0.918 / 0.731 | 0.937 / 0.760 |
| 파라미터 (실측) | 1.94M | 13.42M |
| 이 PC CPU 4스레드, 640×384 | 144ms | 136ms |
| 이 PC GPU, 전체 처리 FPS | 34.3 (640×480) | 21.5 (640×512) |

- TwinLiteNet+ Large는 파라미터는 적지만 연산량이 17.58G MACs(640×384, thop 측정)로 적지 않다.
- HybridNets는 thop이 4.28G로 보고했지만 커스텀 합성곱을 빠뜨렸을 가능성이 커서 쓰지 않는다.
- GPU 수치는 RX 9070 XT + ZLUDA 벤치마크(`outputs/benchmarks/`)라 Jetson 속도로 환산할 수 없다.
- TensorRT 변환은 두 모델 모두 시험하지 않았다. HybridNets는 ONNX 변환 전에 활성화 함수 설정을 바꿔야 할 수 있다. 엔진은 보드에서 직접 만들어야 한다.

## 배포 전에 확인할 점

1. **카메라 설정 불일치:** 통합 실행(`teleop_launch.py`)이 Dabai DC1이 아니라 `astra_stereo_u3` 설정으로 카메라를 켠다. 학습 데이터는 1280×720이므로 주행 때 해상도와 화각이 같은지 먼저 확인한다.
2. **인식이 끊겨도 멈추지 않음:** `/control`을 한 번 받으면 이후 멈추는 조건이 없다. 현황 문서의 수정안대로 새 값이 0.5초 동안 없으면 정지시킨다. 무거운 모델을 올릴수록 중요하다.
3. **기존 DL 주행 속도:** 직선에서 0.5m/s로 달린다. 규정 권고는 0.3~0.4m/s다.
4. **출력 형식:** 기존 노드는 `/control` 또는 `/distance_y` 값 하나로 조향한다. 우리 모델 출력은 마스크이므로 마스크에서 이 값을 만드는 부분을 주행 담당과 정한다.

## 나중에 보드에서 할 일

```bash
cat /proc/device-tree/model
nvpmodel -q
free -h
```

1. 위 명령으로 모듈과 전력 모드, 메모리를 확인한다.
2. 두 모델을 학습 입력과 같은 640×384로 측정한다. `scripts/benchmark_models.py`는 640×480 기준이라 그대로 쓰면 조건이 다르다.
3. TensorRT 변환 후 다시 측정해 비교한다.

## 규정에서 차선 인식과 관련된 내용

- 트랙 10m×6m, 차선 폭 550mm, 곡률 안쪽 R600 / 바깥쪽 R650, 시계 방향 1바퀴, 제한시간 10분.
- 차로 이탈은 한쪽 앞뒤 바퀴가 선을 넘을 때 판정되고 회당 -1점이다.
- 지그재그 구간(15점)은 직전 헤딩을 유지하며 서행 통과한다.
- 라바콘 구간은 차선 판정이 없다.
- 3차선 구간에서는 정차 LIMO 7대를 차선 변경으로 회피한다.
- 신호등, 표지판 실물은 대회 측에서 아직 제작 전이다(2026-10-31 기준).
